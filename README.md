# horizon

DeepSeek Harness 的用量与花费显示插件。

输入框上方常驻账户余额，点开能看今天的用量和花费，每条回答末尾也会标出这一轮花了多少钱。

## 显示什么

- 输入框上方一行：`⛁ 余额 ¥128.00`
- 每条回答的按钮行：`⛁ 用量 7.5M tok　¥0.18　03:15`，悬停可看输入、输出、缓存明细
- 点余额展开面板：今日总量、24 小时柱状图（悬停显示那一小时的花费和忙/闲）、按模型拆分

## 安装

侧边栏 → 插件 → 填 `https://github.com/iammralmost/horizon`。装完按 `Ctrl+R` 刷新；没变化就完整退出 DSH 再打开。

也可以用 `plugin_manager` 的 `install_bundle` 装同一个地址。

## 价格

DSH 不存单价，所以费用是按 `prices.json` 算出来的估算值，不是平台账单。

内置了 `deepseek-flash` 和 `deepseek-v4-pro` 的官方价，单位是人民币元/百万 token，填的是高峰价，闲时按 `offPeakDiscount` 打折。高峰时段按官方规则：工作日 9:00–12:00 和 14:00–18:00，其余时间含周末都算闲时。

**法定节假日要自己加**到 `peak.holidays`（格式 `2026-10-01`）。不加的话，那天会被当成高峰计价，费用会高估一倍。

换模型就改 `models` 里对应那行，不用重新安装。

## 几点说明

- 余额走平台接口，今日用量读本机会话日志，都不消耗 token
- 只统计本机的会话，别的设备或网页版的用量不会算进来
- 余额缓存 60 秒，今日用量缓存 90 秒，点面板里的「刷新」才会强制重算
- 针对 DSH 0.2.1-rc.5 的界面结构写的。其中把花费排到「用量」和「时间」之间用了 CSS 重排，DSH 改版后位置可能会跑，但数字不会消失
